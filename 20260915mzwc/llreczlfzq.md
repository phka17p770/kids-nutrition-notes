# 三天鲜胚级别7优是什么意思？

> 更新时间：2026-09-15 (UTC+8)

备孕2年，未怀孕，男方精子检测没有问题，我两侧输卵管通而不畅，期间做过门诊促排4个月，后转试管。5月取卵10枚，移植鲜胚一枚未着床，5枚养囊全部失败。然后又重新开始促排，取卵8枚，今天是取卵后三天，鲜胚已经培养好了，这次没有养囊，医生告诉我是7优，想知道这是什么意思？鲜胚级别又是怎么样的？ 
查看全部内容

7优是指这个鲜胚是7细胞的优质胚胎。三天鲜胚的级别主要是根据第三天胚胎发育速度卵裂球数目、卵裂球的均一度及胚胎碎片数量来划分的。按照受精卵分裂的规律，一般胚胎生长到第3天应该具有8个细胞，但实际中因为胚胎发育快慢不一，所以认为具有6-10个细胞的胚胎都具有较好的发育潜能，可用于移植。因此，7优就是7细胞，说明这个胚胎发育潜能较好，算优质胚胎。

试管婴儿胚胎的等级，其实是按照胚胎质量的好坏来分的。通常也将试管婴儿的胚胎分为四级，A级，B级，C级和D级，A级为优秀胚胎，B级为良好胚胎，C级为一般胚胎，D级为不能使用的胚胎。其实与I级、II级、III级和IV级都是相对应的，只是不同医院称呼不一样，D3胚胎评级具体如下：

- 1. I级的胚胎发育速度是处于一个正常的状态，细胞质均一，也没有空泡，并且卵裂球也比较均匀、数目相等，其中最主要的是一级胚胎的碎片数量非常的少，碎片0%-5%；
- 2. II级的也是胚胎发育速度正常，卵裂球的好坏和一级一样，它的数目均等，细胞质均一，也没有产生空泡，碎片占6%-20%；
- 3. III级的是胚胎发育速度趋于正常的速度，卵裂球处于均匀和不均匀之间，数目也是处于不均等和均等之间，细胞质中含有少数空泡，碎片21%-50%；
- 4. IV级的是胚胎发育速度是异常的状态，卵裂球也是非常的不均匀，并且数目也不均等，细胞质不均一和有大量空泡，碎片大于了50%。

相信不少患者看到鲜胚级别都是有点懵的，因为有的是显示A级，B级，C级和D级，有的是一级、二级、三级和四级，其实这都是不同医院说法不一样。
比如胚胎移植报告还有显示11/8的，这里前两个1分别代表着卵裂是否均一、碎片程度，而8代表卵裂球细胞数目。11/8就说明这个胚胎卵裂均一度和碎片程度都为I级，有8个细胞。
